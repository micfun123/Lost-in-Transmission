name: ship
description: Branch, commit, push and open a PR for the current task
---
1. Run git status. Create a branch named after the task (kebab-case) from an up-to-date main.
2. Make small, clear commits. Add NO Claude/AI attribution.
3. Push with -u and open a PR using `gh pr create` with a summary and test notes.
4. Report the PR URL.
